# Security Audit Methodology

## Purpose

This project performs lightweight, non-destructive checks
against common Linux security configurations.

## Principles

- Read-only inspection where possible
- No exploitation
- No modification of system configuration
- Clear and reproducible findings
- Suitable for authorized systems only

## Planned Checks

1. Sensitive file permissions
2. User and group configuration
3. Running services
4. SSH configuration
5. Weak security defaults
6. Severity classification
